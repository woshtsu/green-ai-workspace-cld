## Pruebas por servicio (Windows/PowerShell, desde la raíz)
```powershell
cd software\monitoring; .\mvnw.cmd -B verify; cd ..\..
cd software\gateway; .\mvnw.cmd -B verify; cd ..\..
cd software\simulator; uv run --frozen python -m unittest discover -s tests; cd ..\..
cd software\data-processing; uv venv .venv; uv pip install --python .venv\Scripts\python.exe -r requirements.t
cd software\prediction; uv venv .venv --python 3.11.9; uv pip install --python .venv\Scripts\python.exe -r req
cd software\frontend; node --test tests/frontend.test.cjs tests/prediction.test.cjs tests/recommendations.test
```

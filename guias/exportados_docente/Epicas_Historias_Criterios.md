# Matriz de Épicas, Historias de Usuario y Criterios de Aceptación

|  |  |  |
| --- | --- | --- |
| Épica (por módulo) | Historia de Usuario | Criterios de Aceptación (Given / When / Then) |
| Gestión de Datos | Como administrador necesito importar datos históricos de reservas para que el sistema entrene el modelo de predicción. | Escenario 1: Importación exitosa Given que selecciono un archivo válido de reservas históricas When lo cargo al sistema Then el sistema confirma la carga y almacena los datos en la base.  Escenario 2: Error en formato Given que selecciono un archivo en formato incorrecto When intento cargarlo Then el sistema muestra un mensaje de error indicando el formato esperado. |
| Gestión de Datos | Como administrador necesito integrar datos externos (clima, festividades, vuelos) para enriquecer las predicciones de demanda. | Escenario 1: Conexión exitosa Given que ingreso credenciales válidas de la API When pruebo la conexión Then el sistema confirma la integración.  Escenario 2: Conexión fallida Given que configuro credenciales inválidas When pruebo la conexión Then el sistema muestra un mensaje de error indicando la causa. |
| Motor de Predicción (IA) | Como gerente necesito visualizar predicciones de ocupación semanal para ajustar tarifas y disponibilidad. | Escenario 1: Predicción disponible Given que existen datos históricos suficientes When solicito predicción semanal Then el sistema muestra la ocupación estimada con nivel de confianza.  Escenario 2: Datos insuficientes Given que los datos históricos son incompletos When solicito la predicción Then el sistema muestra una advertencia sobre baja confiabilidad. |
| Motor de Predicción (IA) | Como analista necesito generar predicciones mensuales para planificar campañas de marketing turístico. | Escenario 1: Predicción generada Given que selecciono un horizonte de un mes When ejecuto la predicción Then el sistema muestra la demanda proyectada con gráficos de tendencias.  Escenario 2: Configuración inválida Given que selecciono un horizonte no soportado When intento ejecutar la predicción Then el sistema muestra un mensaje con los rangos aceptados. |
| Motor de Predicción (IA) | Como gerente necesito comparar predicciones de ocupación frente a la ocupación real pasada para evaluar la precisión del modelo. | Escenario 1: Comparación exitosa Given que existe histórico de ocupación real When solicito la comparación Then el sistema muestra un gráfico con predicción vs ocupación real y margen de error.  Escenario 2: Sin datos históricos Given que no existen datos reales disponibles When solicito la comparación Then el sistema muestra un mensaje indicando que no se puede generar la comparación. |
| Gestión de Reservas Dinámicas | Como recepcionista necesito recibir recomendaciones automáticas de tarifas dinámicas basadas en predicción de demanda para maximizar la rentabilidad. | Escenario 1: Alta demanda Given que la predicción indica alta demanda When consulto tarifas sugeridas Then el sistema recomienda incrementos en los precios dentro de un rango permitido.  Escenario 2: Baja demanda Given que la predicción indica baja demanda When consulto tarifas sugeridas Then el sistema recomienda descuentos o promociones. |
| Gestión de Reservas Dinámicas | Como recepcionista necesito recibir alertas de sobreocupación o baja ocupación para tomar decisiones rápidas. | Escenario 1: Sobreocupación Given que las reservas superan el 95% de la capacidad When se actualizan los datos Then el sistema envía una alerta de sobreocupación.  Escenario 2: Baja ocupación Given que las reservas están por debajo del 40% When se actualizan los datos Then el sistema envía una alerta para activar promociones. |
| Reportes y Visualización | Como gerente necesito reportes comparativos de predicción vs ocupación real para evaluar la precisión del sistema. | Escenario 1: Reporte generado Given que selecciono el rango de fechas When solicito el reporte Then el sistema muestra gráficos comparativos con métricas de error. |
| Reportes y Visualización | Como gerente necesito descargar reportes en PDF o Excel para compartir con el equipo. | Escenario 1: Descarga exitosa Given que genero un reporte When selecciono exportar a PDF Then el sistema descarga el archivo con los datos correctos. |

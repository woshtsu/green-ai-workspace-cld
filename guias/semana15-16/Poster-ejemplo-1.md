## Bloques en orden de lectura

**Título**
«Implementación de un sistema de análisis predictivo usando técnicas de Machine Learning para la demanda de productos artesanales en la feria de Huancayo, Junín, en el año 2025»

**Autores**
Jhon Flores; Alexander Rafael; Jose Sulla & Jordan Vilcahuaman

**INTRODUCCIÓN** (recuadro)
- *Problema general*: ¿De qué manera implementar un sistema de análisis predictivo usando técnicas de Machine Learning para la demanda de productos artesanales en la feria de Huancayo, Junín, en el año 2025?
- *Objetivo general*: implementar dicho sistema para la demanda de productos artesanales en la feria de Huancayo, Junín, en el año 2025.
- *Objetivos específicos* (3 viñetas): predecir la demanda considerando las características del mercado local; determinar los factores económicos, sociales, estacionales, culturales y otros que influyen en la variabilidad de la demanda; garantizar la precisión y confiabilidad del sistema a lo largo del tiempo y mejorar las recomendaciones de inventario para los vendedores.

**MÉTODOS Y MATERIALES** (columna izquierda)
- **PMV1: Base de datos y gestión fundamental**: texto sobre arquitectura modular, base de datos MySQL, CRUD principales y sistema de autenticación. Figura: diagrama «Arquitectura de Software» (capas: vista/cliente, servicios, datos; con módulos como Angular/Framework, API y base de datos).
- **PMV2: Desarrollo e integración del modelo predictivo**: prueba de concepto del modelo de Machine Learning con limpieza de datos, codificación de variables, entrenamiento de un modelo de Árbol de Decisión y creación de una API para comunicar predicciones al sistema web. Figura: diagrama de árbol de decisión (nodos naranjas).
- **PMV3: Sistema inteligente de decisiones**: integración de los módulos del sistema y funciones para convertir datos y predicciones en recomendaciones accionables; pruebas de usabilidad y optimización final. Figura: captura del dashboard (ventas del día, ingresos totales, promedio de ventas, productos en stock) con gráfico de líneas.

**RESULTADOS** (columna derecha)
- **PMV1**: gestión de inventarios (registrar, ver, actualizar y eliminar productos); captura de pantalla del gestor de inventario; tabla «Top productos vendidos» (nombres de productos y unidades vendidas) y «Resumen de inventario» (total de productos, stock total, precio promedio) con cifras [ilegibles con certeza].
- **PMV2**: gestión de ventas (registrar, ver, actualizar y eliminar ventas del día); captura del dashboard con tabla de productos disponibles y gráfico de barras de productos más vendidos.
- **PMV3**: tabla «Predicciones recientes» (producto, demanda prevista, stock actual, estado, posición, recomendación y fecha) y recuadro «Productos con mayor demanda» con viñetas de productos artesanales (p. ej., Chocolate Artesanal, Textiles de San Pedro de Cajas, Mates Bordados, Poncho de lana, Bolsero de Mate) y cantidades «2 und.».

**CONCLUSIONES Y RECOMENDACIONES** (banda inferior)
- *PMV1*: el módulo estableció la base tecnológica del proyecto (base de datos, CRUD y autenticación), confirmando la viabilidad técnica.
- *PMV2*: el modelo de Machine Learning alcanzó un desempeño satisfactorio (R² entre 0.84 y 0.88); la categoría del producto, el mes del año y los eventos locales tienen impacto en la demanda; la integración con el backend permite generar y visualizar predicciones en tiempo real.
- *PMV3*: integró todos los componentes con dashboards y recomendaciones automáticas, demostrando un sistema funcional, escalable y útil para la gestión de inventarios.
- *Recomendaciones* (5 puntos): (1) incrementar el volumen y variedad de datos, incluyendo información meteorológica, comportamiento turístico y tendencias estacionales; (2) probar modelos más avanzados (Random Forest, Gradient Boosting o redes neuronales); (3) incorporar un módulo móvil para que los artesanos consulten predicciones; (4) integrar análisis de precios y rentabilidad; (5) implementar alertas automáticas por baja demanda, sobreproducción o agotamiento de stock.

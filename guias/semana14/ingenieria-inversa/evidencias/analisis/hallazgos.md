# Matriz de hallazgos — Prompt 11

> **Rol:** Auditor de Software · **Fase 6** · Consolida la evidencia de Auditoría (F1), Dependencias (F2), Configuración (F3), Ejecución (F4) e Ingeniería Inversa (F5).
> **Severidad:** Crítica · Alta · Media · Baja. **Prioridad:** P1 = inmediata (antes de seguir usando el entorno en la nube) · P2 = corto plazo (próximo sprint) · P3 = mediano plazo · P4 = cuando haya capacidad.

## 1. Matriz

| ID | Hallazgo | Evidencia | Impacto | Severidad | Recomendación | Prioridad |
|---|---|---|---|---|---|---|
| H-01 | **El Gateway puede eludirse en la nube**: Prediction y Data Processing se despliegan como servicios web públicos y no tienen autenticación propia | `render.yaml` (`type: web` para ambos); `prometheus.render.yml` hace *scrape* a `https://green-ai-prediction-dev-zxly.onrender.com`; URLs públicas listadas en `docs/`; E50/E51: `GET /api/v1/historical-logs` y `POST /v1/predictions` → 200 sin `Authorization` (L-01) | Cualquiera en Internet puede leer históricos de Supabase usando el token de servicio de Data Processing y consumir la inferencia; RBAC y CORS quedan sin efecto; consumo de horas del plan gratuito (DoS) | **Crítica** | Servicios privados o red privada; si no es posible, validar el JWT de Supabase en cada servicio (mismo verificador del Gateway) o exigir una cabecera firmada por el Gateway; retirar las URLs públicas de la documentación | **P1** |
